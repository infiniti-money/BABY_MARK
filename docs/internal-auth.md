# Tài khoản nội bộ D1 — không dùng Supabase Auth cho Cloudflare
Admin tạo tài khoản; không có endpoint đăng ký công khai. Username có thể là mã NV. Mã đăng nhập 48 ký tự hex (192 bit ngẫu nhiên) chỉ hiển thị khi tạo/cấp lại. Không cho nhập mật khẩu ngắn do người dùng tự chọn; SHA-256 có salt ở đây chỉ phù hợp bí mật ngẫu nhiên entropy cao, không dùng cho mật khẩu con người chọn. Lưu mã bằng password manager, gửi riêng từng nhân viên qua kênh an toàn. Nếu muốn mật khẩu dễ nhớ, cần KDF phù hợp và kiểm thử giới hạn CPU Workers (không giảm bảo mật để giữ free). 
## Cài đặt
1. D1 mới chạy 0001_initial.sql, 0002_store_catalog.sql, 0003_internal_auth.sql. Nếu đã có D1 cũ, chỉ áp dụng script chưa chạy. Binding DB và TIMEMARKS như cũ. Không cần SUPABASE_AUTH_URL hay SUPABASE_PUBLISHABLE_KEY trên Pages Cloudflare.
2. Trên máy tin cậy, Node 22: node cloudflare/scripts/bootstrap-admin.mjs admin-babymark. Lưu mã vào password manager. Chạy nội dung file bootstrap-admin.local.sql trên D1 Console đúng project. Xác minh hồ sơ admin và credentials cùng ID; xóa file local sau khi dùng. Không gửi mã qua GitHub, không commit SQL, không chạy lại tạo admin. Recovery admin thực hiện bởi người có quyền DB, dùng mã ngẫu nhiên mới và thu hồi session.
3. API /api/auth/login POST {username,secret}; /api/auth/me GET; /api/auth/logout POST {}; /api/auth/accounts GET (admin); /api/auth/create POST {username,employee_code,full_name,department,role}; /api/auth/reset POST {user_id}; /api/auth/set-active POST {user_id,active}. Ngoại trừ login, gửi Authorization: Bearer <token>. Token phiên 8h, chỉ lưu hash trong DB. Khóa/cấp lại mã thu hồi phiên. Admin bootstrap không thể bị khóa từ API.
4. D1 photo endpoint dùng session nội bộ. Tài khoản manager cần branch_managers được cấu hình riêng; mặc định chưa có quyền cửa hàng.
5. Đây là backend xác thực pilot, chưa thay toàn bộ frontend web/mobile Next.js/Expo hiện hữu. Không coi đã chuyển hệ thống nghiệp vụ sang Cloudflare. Kiểm thử D1 thật, giới hạn brute force theo IP tại Cloudflare, giới hạn kích thước request trước Worker, quota D1, session revocation, lỗi song song và phân quyền trước production. Không dùng tài khoản thật trong thử nghiệm. Dọn sessions hết hạn định kỳ.
