# HR completion (phase 1)
Adds optional private CV metadata: contract reference/type/start/end, probation period/result, training, reviewed performance, career history, confirmed disciplinary notes, and salary-decision references. Uses existing schema 0021, retains revision guard and audit metadata. Does not change payroll or employment status. All fields accessible only to owner or Admin; Admin edits. Do not include ID documents, confidential third-party notes, bank details or unverified allegations. Deadline dashboard is Admin-only, shows active profiles whose entered contract/probation end dates are overdue or within 30 days; recorded probation result suppresses probation reminder. It is not a legal determination or automatic notification. No automatic account lock or contract renewal. Single current contract/probation metadata, not a multi-contract archive. Print A4 portrait via browser print / Save as PDF, freshly fetch saved record, no server-side file or external service. 
Still pending: secure portrait/document storage with approved quota and retention; multi-contract historical ledger; employee self-service changes with approval; bulk import; leave balances/types, future replacements, published payslips and formal payroll rules; device and backup acceptance. No migration or paid service. Production requires CI and explicit rollout.
