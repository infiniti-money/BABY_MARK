# BABY MARK — Timemark
The common layout embeds the actual repository logo. Server timestamp in Asia/Ho_Chi_Minh with seconds, assigned branch, employee/name/code, IN/OUT, scheduled start/end, GPS coordinates/accuracy, distance/radius, status and address. If reverse geocoding is unavailable, display "Chưa xác định địa chỉ" instead of invented address. Image area is above the metadata panel; logo at upper left. Data shown in examples is fictional.
- cloudflare/lib/timemark-layout.mjs: server-side SVG overlay, portable to Workers and Node.
- apps/web/lib/render-timemark.mjs: Sharp-based final JPEG renderer, 800×1066 initially, adaptive resolution/quality with hard 200 KB cap. Shared by Web and Expo through a trusted server API. Requires Node runtime, installed dependencies and Vietnamese-capable fonts. Reject image if cap cannot be achieved; test readability before production.
- POST /api/cloudflare/timemark-preview: D1 account bearer token; own assigned shift; server clock, D1 store and profile, validated GPS, distance. Preview only, not evidence or record creation. No Supabase Auth in this endpoint. Client GPS is not proof against spoofing.
- Cloudflare Pages/Workers free runtime does not run native Sharp as a drop-in dependency. Final JPEG encoding and trusted upload into KV still require a verified compatible renderer or separate trusted Node processor. Never accept a client-generated watermark as server evidence. No final Cloudflare attendance write route is enabled by this commit.
- Test using node --test cloudflare/tests/*.test.mjs and npm test in apps/web after dependency installation. No deployment or device build implied.
