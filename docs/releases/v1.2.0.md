# BABY MARK v1.2.0 — HR Management

## Improvements
- Role-based mobile navigation, touch targets, request review and chat; HR profiles, employment and CV printing.
- Server-side attendance report pagination with complete totals and full exports; optional D1 migration 0022 adds two indexes.
- Lazy loading of camera/Timemark, CV and report modules; public static asset revalidation and API-only Pages Functions routing.
- Camera/GPS cancellation and resource cleanup, bounded polling and retry backoff, recovery after connectivity loss without blind retry of writes.
- Correct D1 trigger-inclusive change counts using RETURNING; preserve attendance/payroll rules, authorization and immutable closed payroll.
- New photo maximum retention 90 days, existing expiry unchanged; 200 KB photo cap and 900 MB budget remain. No new paid services.
