## RC.7 — payroll and recovery safety

### 0020 explicit work-unit review
Admin can explicitly review a valid short full-day shift with 0/0.5/1/1.5/2 units and mandatory reason, no default value. Review is append-only and bound to the original attendance/request evidence; changed evidence invalidates the review. Approval increments payroll epoch. No statutory or company entitlement rule is assumed. Other abnormal records remain blocked until reconciled. Existing absence handling remains explicit in the closing checklist. The earlier statement that legitimate short-day review has no workflow is superseded by this change. Demo closing test now submits the reviewed epoch.
