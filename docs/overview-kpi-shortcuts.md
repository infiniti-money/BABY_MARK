# Overview KPI shortcuts
The ten overview counters are real buttons. Active store and employee totals open the corresponding Admin directory with active-only filtering (employees excludes Admin, matching the counter). Attendance metrics use the already-loaded overview snapshot, retain the selected date/store, reset page to 1 and scroll/focus the detail table. Combined states include both component statuses; scheduled excludes rejected extras, unit/OT filters show positive values rather than counting them as rows. Clear filter restores all rows. No server/API, database or payroll calculation changes. Keyboard and responsive support; regression test covers each route/filter. Production release requires CI and approval.
