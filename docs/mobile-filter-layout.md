# Phone filter layout
The operator supplied screenshots from the live iPhone Web App showing overlapping native date fields in schedule, history, handover, overview and the audit dialog. A shared mobile-filter-stack class applies to the common date/report filter, overview, calendar, audit, payroll and admin search. At <=620px and compact phone landscape, controls use one zero-minimum grid track, 56px height, 12px row gap, 16px radius, and 16px control font. Native date/month picker appearance is preserved; the checkbox retains its own size. Desktop and normal tablet layout remain unchanged. No API, permissions, payroll or database changes. Mobile CI covers geometry and real filter submissions, including calendar dialog and audit source/date. Native operating-system date picker UI itself requires physical-device testing.
