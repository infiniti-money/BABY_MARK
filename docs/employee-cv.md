# Employee CV (RC.17-HR)
Admin: Quản trị → Nhân viên → Hồ sơ CV. Employee/manager: Hồ sơ của tôi in sidebar. Admin edits staff/manager records; employee/manager can read own CV only. No manager access to other CVs, even in own store. No CV values in staff directory, audit metadata or reports. Existing profile name, employee code, role, department and account status remain authoritative; existing employment periods and assigned stores are read-only context, not invented employment history.
Optional structured fields include birth date, phone, email, address, position, summary, education, experience, skills, languages, certificates, achievements. Text only; no photo/document uploads, export or personal financial/government/health data. Minimize collection and restrict backup access. Employee can ask Admin to correct or clear values. Revision check prevents stale overwrites; audit trigger records revision only. No independent tamper-proof ledger. 
Migration 0021_employee_cv.sql is additive. Back up D1, apply to correct DB once, verify table and two triggers; no changes to existing attendance, accounts, payroll or KV. Health target 0021 after deployment. Before migration CV is unavailable but existing functions remain usable. No production migration/deploy performed.
