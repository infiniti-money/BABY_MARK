# BABY MARK Mobile v0.4
Project Expo SDK 54. Node 22 LTS. cd apps/mobile; npm install; copy .env.example to .env; configure HTTPS API URL, Supabase URL and publishable key. Never use service role key. npx expo install --check; npx expo-doctor; npm run bundle. Commit package-lock.json after verified dependency resolution; the lockfile is not yet present.
For native push, eas init; configure FCM v1/APNs and EAS project ID. Run eas build --profile development --platform android (or ios), install dev build and npm start. Use preview profile to produce APK for internal testing. iOS signing requires Apple account. See docs/notifications.md.
Features: staff login, shift selection and store name, camera, GPS, server timemark, own recent attendance history, notifications and link to web leave/correction. Requests currently use mobile web login, not native request form.
Mock detection is platform-dependent and not equivalent to device attestation. Test permissions, accuracy, native upload, signed-in session, push and logout on physical devices. Upgrade Expo SDK and dependencies before production if required. Logo asset is provisional for app store; high-resolution icon and store review required.
